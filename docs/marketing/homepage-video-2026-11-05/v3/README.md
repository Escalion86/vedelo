## Нужна ли музыкальная плашка

Обязательно указание авторства и лицензии при использовании этой музыки по CC BY 4.0. Большой блок внутри кадра не требуется: автор разрешает размещать сведения в видео либо его описании. [Правила автора](https://incompetech.com/music/royalty-free/faq.html), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

В видео оставлен краткий кредит. **При размещении на сайте сохраните полную строку со ссылками под плеером из `preview.html`.** Для видеохостинга перенесите текст из `MUSIC_CREDITS.md` в описание. Там указаны источник, лицензия и обработка музыкального фрагмента.

Для встраивания загрузите выбранный MP4, обложку и VTT, затем подставьте их адреса в `preview.html`. Сохраните `controls`, `playsinline` и `preload="metadata"`. По умолчанию подключена версия 1080p. Сайт и доступность функций приложения в рамках монтажа не менялись.

# Ведело — версия 2 с комиксами и музыкой

Обновлённый ролик для главной страницы, 05.11.2026. Продолжительность — 1:48,85; горизонтальный формат 16:9, 30 кадров/с. Первая версия сохранена в родительской папке.

## Что изменилось

- На словах об опыте появляется крупный акцент «20+ лет».
- Рассказ о блокноте, заметках, календаре, потерянных деталях, звонках и оплатах сопровождают проблемные сцены из ранее созданных комиксов.
- На переходе к другим специальностям показаны фотограф, мастер и кондитер. Вставки плавно сменяются рядом с ведущим.
- Под голосом звучит лёгкая инструментальная музыка без вокала. Она дополнительно приглушается во время речи.
- Сохранены весь рассказ, реальные вставки UI, блок о бесплатных возможностях, дополнительный рассказ об ИИ и финальное приглашение. Субтитры подходят обеим версиям без изменения таймингов.

## Комплект для сайта

| Файл | Назначение |
| --- | --- |
| `vedelo-home-v2-1080p.mp4` | Основной файл Full HD с музыкой, 47,4 МБ. |
| `vedelo-home-v2-720p.mp4` | Облегчённая версия для мобильного просмотра, 16,4 МБ. |
| `vedelo-home-poster.jpg` | Обложка 1920 × 1080. |
| `vedelo-home-ru.vtt` | Отключаемые субтитры для сайта. |
| `vedelo-home-ru.srt` | Субтитры для видеохостинга или редактора. |
| `preview.html` | Готовый пример плеера с обложкой и субтитрами. |
| `MUSIC_CREDITS.md` | Автор музыки, лицензия и источники. |

Для размещения загрузите MP4, обложку и VTT. Возьмите `<video>` из `preview.html` и подставьте адреса файлов. В примере подключён Full HD; при необходимости замените его на 720p. `controls`, `playsinline` и `preload="metadata"` сохраните; автоматического запуска со звуком нет. Сервер должен поддерживать MP4, MIME `text/vtt` для субтитров и запросы диапазонов для перемотки. Проверять VTT следует через HTTP.

Музыка: **Life of Riley — Kevin MacLeod**, CC BY 4.0. Кредит встроен в финал видео и размещён в примере плеера; детали в `MUSIC_CREDITS.md`.

Перед публикацией владелец откроет доступ к распознаванию заказов по фотографии, как согласовано ранее. Функционал приложения и production в рамках монтажа не менялись. Исходная запись и предыдущая версия не перезаписаны.

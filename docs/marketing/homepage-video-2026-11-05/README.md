## Размещение на сайте

Загрузите выбранный MP4, обложку и VTT в одну папку и используйте элемент `<video>` из `preview.html`, заменив пути на адреса загруженных файлов. В примере подключена версия 1080p; для меньшего объёма замените её на 720p. Две версии не переключаются автоматически по скорости соединения.

Оставьте `controls`, `playsinline` и `preload="metadata"`; запуск — по нажатию посетителя. Сервер должен отдавать MP4 как `video/mp4`, VTT как `text/vtt` и поддерживать запросы диапазонов байтов для перемотки. Для проверки субтитров открывайте пример через HTTP, поскольку локальное открытие HTML может ограничивать загрузку VTT.

Оригинальная запись не изменена. Монтаж и распознавание речи выполнены локально; исходное видео не загружалось во внешние сервисы. Исходники монтажа сохранены рядом с комплектом: `edit.json`, `build_video.py`, `graphics.html`, `capture_graphics.cjs`.

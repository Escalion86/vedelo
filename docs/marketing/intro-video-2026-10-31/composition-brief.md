# Визуальные вставки справа от ведущего

Собрать видео по brag-plan.md. Автор снимает себя отдельно. Основной материал — настоящий Web UI, отрисованный из исходников на вымышленных данных без запросов к рабочему аккаунту.

Выход: vedelo-ui-inserts.mp4, 864 × 1080, 30 fps, 21 секунда. Дополнительно три самостоятельных MP4 по 7 секунд для свободной расстановки под речь. Без аудио. Фон тёплый светлый. В окончательном горизонтальном кадре панель располагается справа, автор слева.

Три сцены: договорённости, следующий контакт, оплаты. Основные заголовки 54–64 px, пояснения 28–34 px; карточки показываются крупно, без мелкой навигации браузера. Сцены не изображают полный интерактивный путь регистрации или создания заказа.

Использовать локальные шрифты public/fonts/InterTight-* и FuturaPT-Bold. Runtime GSAP локальный. Для появления пояснений адаптировать установленный staggered-fade-up. Вход около 0,5 секунды, читаемое удержание не меньше 4 секунд на сцену. Избегать фальшивого курсора и пропуска подтверждений под видом реального взаимодействия.

Проверить HyperFrames check, промежуточные кадры каждой сцены и финальные MP4 через ffprobe. Запрос пользователя создать видео является разрешением на локальный рендер; внешняя публикация не запрашивалась.

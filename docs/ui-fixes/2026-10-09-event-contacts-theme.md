# Дополнительные контакты заказа: светлая тема

Версия: 1.35.10. Статус: исправлено, проверено локально и выложено на https://vedelo.ru; BUILD_ID `AgqHT0ryQt73sTgZX9gtk`. Отчёт выкладки: `docs/deploy/2026-10-09-contacts-theme.md`.

## Причина и изменение

- Меню дополнительных контактов настоящего EventCard использует DropDown, в котором `dark:bg-gray-800` и `dark:border-gray-700` реагируют на системную тему, а не на выбранную тему Ведело.
- При светлой теме Ведело и тёмной теме ОС воспроизведён фон RGB(30, 41, 57), несмотря на светлый заголовок карточки и выбранную светлую тему приложения.
- Добавлен отдельный CSS-модуль `layouts/cards/EventCard.module.css`: только для дополнительных контактов и `body:not(.theme-dark)` фон/рамка берутся из `--surface-card-bg`/`--surface-card-border`.
- Общий DropDown, размеры, отступы, содержимое, способы связи и оформление тёмной темы не изменены.
- Старый статический стенд карточек научен компилировать CSS-модули через esbuild с настоящими именами классов и включать их CSS; он больше не пытается разбирать CSS через SWC как JavaScript.

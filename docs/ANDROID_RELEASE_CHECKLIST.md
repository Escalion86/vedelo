# Android 1.0 — release checklist

Этот чек-лист фиксирует выпускной порог для пользовательского приложения «Ведело». Разделы администрирования тарифов, пользователей и ролей, PartyCRM и dev-инструменты в Android-приложение не входят.

## Сборка

- [x] `POST_NOTIFICATIONS` запрашивается только после явного включения push; `RECORD_AUDIO` — только после нажатия «Записать голос». Системные `VIBRATE`, `RECEIVE_BOOT_COMPLETED` и `MODIFY_AUDIO_SETTINGS` используются push/audio инфраструктурой.
- [x] Нет `READ_CALL_LOG`, `WRITE_CALL_LOG`, `PROCESS_OUTGOING_CALLS` и `SYSTEM_ALERT_WINDOW`.
- [ ] На Android 13+ проверен понятный сценарий отказа и повторного включения уведомлений.
- [ ] Проверены отказ в доступе к микрофону, повторная попытка, запись/остановка AI-черновика и отсутствие фоновой записи; disclosure совпадает с фактической отправкой аудио и текста настроенному AI-провайдеру.
- [ ] Document Picker, отправка расшифрованной временной копии и очистка app cache проверены на физическом устройстве.
- [ ] Перед добавлением камеры/сканера отдельно подготовлено disclosure для `CAMERA`.

## Реализация

Общий production-компонент по одобренному примеру, не iframe/вставка статического HTML. Используй реальные токены InputWrapper/AppButton, а не фиксированные hex из демо. Песочная подпись, одна тонкая рамка, календарь слева, шеврон справа; отдельная круглая кнопка сброса на телефоне, овальная с текстом на широком экране. Первая панель содержит только готовые периоды; «Выбрать даты» — отдельный экран календаря. Ручной ввод ДД.ММ.ГГГГ появляется только по кнопке. Календарь доступен и в 280px/390x640; не показывать одновременно пресеты, календарь, поля и селекторы года/месяца. На телефоне один месяц, на большом экране допускается два. Названия пресетов компактны, полный диапазон доступен в title/accessible name. Быстрые периоды применяются сразу; календарь/ввод в draft до «Применить». Закрытие, отмена, Escape/клик снаружи не меняют контролируемое значение. Открытие берёт актуальное внешнее значение; обновление родителем при закрытии учесть. Фокус: при открытии внутрь, Tab не уходит за modal, Escape/back возвращает триггер; portal не обрезается сворачиваемыми панелями/overflow, корректный z-index в существующих модалках. Disabled блокирует триггер и сброс. Не допустить двойной календарь/двойную рамку.

Контракт границ: YYYY-MM-DD, строго существующая дата (29 февраля, неверный день/месяц/незавершённый ввод), без UTC-сдвига локального дня. По умолчанию локальная дата, параметр UTC для ServiceAnalytics. Пресеты «За всё время», «Сегодня», «Последние 7 дней» (включая сегодня), «Текущий месяц», «Прошлый месяц»; в аналитике текущий месяц до сегодня, не последний будущий день. Сохрани контекстные «Завтра», «На выходных» транзакций. Открытые границы и сброс к пустому диапазону только где уже разрешены. Обязательные диапазоны принимают resetValue исходного периода; скрывать «За всё время». Компонент принимает maxDate/maxDays/required-range либо эквивалент; проверка ограничений блокирует Apply и недопустимые пресеты, не отправляет заведомо неверный API-запрос.

5. `layouts/content/ServiceAnalyticsContent.js`: обе даты обязательны, UTC, maxDate=today и 1–366 дней (`server/serviceAnalytics.mjs`). 6. `components/GoogleCalendarImportSettings.js`: обе даты обязательны, исходно сегодня→+6мес; сброс к initialRange, atomically обновить state; loading/importing блокируют изменение. Локальная ISO-конвертация начала/конца дня, preview selection, re-preview/loading — сохранены.

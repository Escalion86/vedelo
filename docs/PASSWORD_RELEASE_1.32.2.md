## Android

- Облачный профиль `production-apk`, production API `https://vedelo.ru/api`.
- Пакет `ru.escalion.vedelo`, версия 1.1.0; номер финальной отправки 26 (промежуточные номера израсходованы при прерванных отправках).
- Используется существующий удалённый keystore, общий с прежними сборками; новый ключ не создавался.
- Текущий Android-клиент включает установку первого пароля и ранее подготовленные изменения паритета.
- Перед финальной отправкой исправлены две недостаточно контрастные текстовые пары только светлой темы: cardMuted #656b77 и selectionText #755c30. Диагностика теста теперь перечисляет все неудачные пары; минимальный контраст не ослаблен. Тёмная тема не менялась.
- Typecheck прошёл; полный итоговый Jest: 132 набора / 1315 тестов, все успешно.
- APK и его включённые изменения будут подтверждены по готовому файлу; установка на физическом устройстве не проверялась.

Сборка EAS: `32a8b043-4d7d-4789-b931-44ddfea4bd2e`; последний подтверждённый статус `IN_QUEUE`, готового APK пока нет. Отправка/ожидание продолжается независимо от TUI в user-юните `vedelo-apk-password-release-final`. Проверенный событийный обработчик `vedelo-apk-password-finalize` ждёт закрытия JSON-результата, затем читает точную сборку, скачивает APK, проверяет ZIP, подпись apksigner и маркеры `hasPassword`, боевой API и исправленные цвета в Hermes-бандле. Он не обещает уведомления в TUI.

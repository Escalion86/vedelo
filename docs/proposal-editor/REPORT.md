## Хранение и совместимость

Новые типы `header`, `packagesIntro`, `closing` добавляются к прежним массивам блоков. Наличие полного набора определяет новый вид. Исходные блоки, включая выключенные, остаются в снимке; в новые поля объединяется только видимое содержимое, вместе с заголовками и встроенными медиа. Повторное открытие не восстанавливает архивный текст поверх новых правок. Общий отбор активного содержимого применяется также при проверке переменных перед публикацией. Старые опубликованные снимки без новых типов продолжают читаться прежним способом.

Схемы, права доступа, идентификаторы, нативные экраны и расчёты не менялись. Исправлено сохранение веб-шаблона через существующий PATCH вместо неподдерживаемого PUT; ручной нулевой итог сохраняется. Нативная сборка Android не выпускалась.

Санитайзер принимает только разрешённые шрифты, конечный набор размеров, строгие значения цвета и выравнивания. Произвольные стили, обработчики, скрипты и небезопасные источники медиа отбрасываются. Настоящий `src` проверяется на DOM-узле, а не по совпадению текста внутри `alt`.

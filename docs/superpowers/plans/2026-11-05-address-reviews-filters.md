# Адрес, отзывы и фильтры Web/PWA

Запрос: прямой ручной ввод адреса; бейджи и фильтр истёкших приглашений;
оценка пятью звёздами; скрытие пустого редактора заметки; единый вид кнопок
фильтров; сворачиваемые фильтры пользователей и новые регистрации первыми.

1. Проверить текущие компоненты и серверный lifecycle отзывов. Сохранить
   существующие пользовательские изменения и внутренние events-контракты.
2. Добавить проверки GET `status=expired`: отсутствие ответа и отзыва ссылки,
   граничное время, сочетание с другими условиями и tenant-negative сценарий.
3. Добавить общий `FiltersButton` на существующих filter-control стилях и
   использовать его в отзывах, пользователях и найденных отличающихся кнопках.
   Эталонные мероприятия и история операций используют тот же компонент.
4. В `AddressSuggestField` добавить доступное действие под полем без
   предварительного фокуса; использовать существующий переход в ручную форму.
5. В отзывах добавить status=expired в UI/API, стандартный StatusChip,
   бейдж с пятью звёздами и числовой доступной подписью. Пустой редактор
   заметки открывать только по действию «Добавить заметку».
6. В пользователях оставить поиск видимым, свернуть остальные поля,
   подсвечивать кнопку при фильтре источника/тарифа/поиска. Сортировать по
   регистрации по убыванию; сортировка сама по себе не ограничивает выборку.
7. Проверить реальное взаимодействие в браузерном стенде с компонентами
   проекта на 390/1365 px в обеих темах, консоль и горизонтальный overflow.
   Browser plugin отсутствует; используется установленный Playwright.
8. Запустить профильные Node-тесты и ESLint, проверить diff, обновить
   roadmap/handoff и повысить patch-версию с сохранением чужих правок.

Дополнение пользователя: в задачах раздела «Важное» подпись «Перенести на»
и кнопки «Завтра», «Послезавтра», «Выбрать дату». Третья открывает стандартную
модалку с календарём. Подтверждение сохраняет выбранный локальный день и
исходное время задачи; отмена не сохраняет. Проверить выбор месяца/дня,
ошибку сохранения, блокировку повторного подтверждения, обе темы и ширины.

Серверное создание/изменение отзыва и его tenant-проверки сохраняются.
Проверки используют синтетические данные и не читают production-секреты.

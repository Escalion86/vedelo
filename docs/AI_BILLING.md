# Тарификация ИИ Ведело

Импорт файлов использует отдельный атомарный резерв целого этапа с жёстким пределом списания, возвратом остатка и восстановлением ответов. Операции: `file_analysis` и `file_import`. Описанный ниже резерв одного запроса остаётся для остальных AI-функций. Подробнее: [Импорт из файла](FILE_AI_IMPORT.md).

## Режимы пользователя

- `artistcrm` — legacy-идентификатор общего серверного `AITUNNEL_KEY`; стоимость списывается из существующего `Users.balance`.
- `aitunnel` — личный ключ пользователя из `SiteSettings.custom.aitunnelKey`; Ведело ничего не списывает.
- `deepseek` — временный developer-only режим для анализа готового текста. Распознавание аудио DeepSeek не выполняет.

## Расчёт и списание

1. Для типа операции берутся последние 100 успешных общих запросов.
2. Средняя себестоимость пересчитывается с текущим коэффициентом наценки. До накопления истории используется резерв 1 ₽.
3. Запрос разрешён, только если баланс строго больше рассчитанного резерва.
4. Резерв атомарно списывается до вызова AITunnel.
5. После ответа фактический расход берётся из `usage.cost_rub`, умножается на коэффициент и округляется вверх до копейки. Разница возвращается или досписывается.
6. При сетевой ошибке или ошибочном HTTP-ответе резерв возвращается.

Успешные операции сохраняются в `AiUsage`, а списания дублируются в журнале `Payments` с `purpose: ai`. Для связанных стадий звонка используется общий `groupId`, но расшифровка и анализ тарифицируются отдельно.

## Управление и отчёты

- Пользователь в web и Android: `Настройки -> Интеграции -> ИИ-провайдер` — баланс, пороги по операциям, общая сумма и последние операции.
- Web/PWA дополнительно показывает ориентировочную стоимость распознавания голосового сообщения и полной обработки звонка. Значения рассчитываются из актуальных средних резервов с текущей наценкой; стоимость звонка складывается из расшифровки и анализа. Фактическое списание зависит от длительности записи и ответа провайдера.
- Developer в web: `Настройки сайта -> ИИ и расходы`; в Android — developer-блок внутри настроек ИИ. Доступны коэффициент от 1 до 10, себестоимость, списания, маржа, разбивка по функциям и пользователям.
- Коэффициент наценки задаётся с точностью до сотых; web/PWA принимает как точку, так и запятую в качестве десятичного разделителя.
- API пользователя: `GET /api/ai/usage`.
- API developer-отчёта: `GET /api/ai/usage?scope=admin`.
- Настройка коэффициента: `GET/POST /api/ai/settings` (только developer).

## Переменные окружения

```env
AITUNNEL_KEY=...
AITUNNEL_CALL_ANALYSIS_MODEL=gpt-4o-mini
AITUNNEL_TRANSCRIPTION_MODEL=whisper-1
```

Секретный ключ используется только на сервере и не передаётся в web или Android-клиент.

# Этапы F, G, H: навигационная оболочка Android

Реализация 01.10.2026 по `docs/mobile-parity/BRIEF-D.md` и этапам F/G/H
`docs/MOBILE_PWA_PARITY.md`. Изменения только в `mobile/`, без коммита.
M1-T10 остаётся в работе; устройство и остальные этапы паритета этим заходом
не закрываются. Корневые roadmap и package.json не изменены по границе задания;
версия не повышается. Этот файл фиксирует выполненную часть внутри разрешённой области.

## Реализация

- **F:** собственная панель из пяти слотов: Важное / термин работ / + / Клиенты /
  Меню. Finance/tasks/profile/more зарегистрированы как скрытые routes.
  Бейдж Важного считает незавершённые контакты с датой строго раньше текущего
  времени, как PWA navigation summary, без суммирования финансовых метрик.
  Содержимое Важного остаётся прежним до I/J.
- Панель занимает место в layout: min-height 60 + нижний inset, иконки 30,
  подписи 10/12, gap 3, padding 6×2, FAB 50/radius999/marginTop−16.
  Цвета берутся из существующего ThemeProvider, включая фон панели и FAB.
- Overlay — один native Modal, внутри него доступна та же нижняя панель.
  Повторный тап, переключение панели, затемнение, Android Back и изменение
  маршрута управляют одним состоянием. Экран под ним не размонтируется.
  Шторка ограничена 62% доступной высоты, имеет собственную прокрутку над панелью.
- Подменю работ задаёт общий UI scope через EventsScopeProvider; существующие
  фильтры списка используют то же состояние. Выбор Предстоящие/Прошедшие
  открывает список. Открытие/закрытие overlay не меняет фильтр, календарь и его дату.
- **G:** `menu.ts` — единственный каталог пользовательских путей для всех ролей.
  Настройки закрыты по умолчанию и раскрывают восемь пунктов в порядке плана.
  Пустые группы скрываются, одиночные пункты — прямые строки. Геометрия строк
  42/radius9/gap10/paddingX12, вложенные paddingLeft34; шторка radius16/padding6.
- Профиль, личный тариф/баланс и sync вынесены отдельно. Support badge — 99+;
  прежний запрет глобального support summary для dev сохранён.
  Старый `/(tabs)/more` использует тот же MenuSheet.
- `/more/[section]` проверяет точный whitelist. Неизвестные, административные,
  массивные и prototype-подобные параметры не монтируют Списки и не вызывают API.
- Импорт и экспорт присутствует в каталоге с явным сообщением о недоступности
  этих функций в текущем Android-клиенте. Их реализация остаётся в последующих этапах импорта/экспорта;
  generic-экран, частичный CSV и web-ссылка не выдаются за готовый native-паритет.
- **H:** + создаёт только работу. Параметры `initialStatus=draft|active` и
  `mode=manual|voice|text` передают выбор в `/events/edit/new`; полезные данные
  клиента/черновика не попадают в URL. Иные значения игнорируются.
  Начальное значение применяется один раз; правка и клонирование сохраняют
  прежние правила статуса. Сохранение идёт через существующую локальную очередь.
- Голос/текст доступны при `currentTariff.allowAi`, проверенном через существующий
  личный billing API. Без сети AI-действия заблокированы, ручные варианты доступны.
  Перед микрофоном, upload и разбором текста сеть проверяется повторно.
  Микрофон не запускается автоматически; результат требует «Применить к форме»,
  затем отдельного сохранения. Фильтрация неизвестного clientId сохранена.

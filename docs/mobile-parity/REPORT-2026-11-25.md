# Паритет Web/PWA и Android на 25 ноября 2026 года

## Доработка Web/PWA в 1.48.2

- В карточке клиента видны работы с ним как с основным или дополнительным контактом. В списке транзакций доступны также операции связанных работ. Доходы, расходы и итог считают фактические прямые транзакции, обязательства показаны отдельно. [API](../../app/api/clients/%5Bid%5D/relations/route.js), [карточка клиента](../../layouts/modals/modalsFunc/clientViewFunc.js).
- Копирование и отправка КП перечитывают актуальный статус и срок. Отправка через Telegram проверяет срок на сервере. Продление доступно из карточки истёкшего КП, ранее выданное истёкшее КП остаётся доступным для чтения. [Редактор](../../components/EventProposalsSection.js), [Telegram](../../app/api/proposals/%5Bid%5D/send-telegram/route.js).
- Ежедневная сводка выключается отдельно в разделе уведомлений. При включении используется сохранённое время. [Настройки уведомлений](../../components/PushNotificationsSettings.js).

Прошли 48 профильных Node-тестов и три сценария Edge/Playwright на синтетических данных при 390 и 1365 px в обеих темах. В карточке клиента проверены повтор после ошибки, пересчёт после оплаты и снятие дополнительного контакта до ответа фонового запроса. Для КП проверены продление и блокировка копирования после отзыва. Для сводки проверены выключение, конфликт при сохранении и повторное включение с сохранённым временем. [Карточка клиента](../../tests/components/clientRelations.browser.test.cjs), [КП](../../tests/components/proposalExpiry.browser.test.cjs), [сводка](../../tests/components/dailySummaryPushSettings.browser.test.cjs).

Полная production-сборка Webpack прошла с увеличенным лимитом памяти Node.js. Запуск собранного приложения подтвердил `display: standalone` в манифесте, HTTP 200 на `/sw.js` и `/service-worker.js`, HTTP 401 на новом API связей без сессии. ESLint изменённых файлов и `git diff --check` прошли. Реальный Telegram и развёрнутый production в этой доработке не проверялись.

- Два браузерных теста прошли в Edge через Playwright при последовательном прогоне. Первый параллельный запуск достиг лимита времени. На синтетических данных проверены получение задатка, перенос задачи и раскрытие «Важного» при 390 и 1365 px в обеих темах, а также статус и повтор синхронизации Google Calendar на карточке. [Задаток](../../tests/components/receiveDeposit.browser.test.cjs#L7), [Google Calendar](../../tests/components/eventCalendarSync.browser.test.cjs#L60).

Сотовые звонки, выдача системных разрешений, виджет и push в этой проверке подтверждены исходниками, содержимым dev APK и прежней документацией в пределах указанных там сценариев. Реальная доставка, текущий production и внешние провайдеры требуют сквозной приёмки.

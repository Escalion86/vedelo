- Сводка: переносимые капсулы с точкой 7, текстом 12/700, подписями и относительным порядком PWA. Область нажатия минимум 40. - Порядок блоков: прошедшие заявки → закрытие → просрочено/сегодня/завтра → без следующего шага → синхронизация → ближайшие работы → даты клиентов. Очередь, её загрузка и ошибка видны отдельно от чтения основных данных; сохранённые счётчики операций не исчезают при ошибке чтения.
- Задачи: круг 24 внутри цели 40, название 14/600, срок/комментарий/контекст 12, меню 32 внутри цели 40. Переносы — компактные кнопки; редактирование и удаление — существующий `QuickActionsSheet`. Сохранены подтверждение удаления, редактор с валидацией, complete/undo/postpone/edit/delete, ошибки и блокировка повторов. Выполненные: зелёные, с ✓, без зачёркивания; дата `Выполнено: doneAt ?? date`.
- Заявки: имя клиента → тип → дата; переносимая горизонтальная группа действий. «Открыть заявку» имеет слабое оформление. Первые 5, затем ещё по 10; счётчик полный. Закрытие, отмена и перенос по-прежнему только открывают существующий редактор, не записывают статус заранее.
- Значимые даты — целиком нажимаемые строки, сведения слева, дата и срок справа. Длинные сведения переносятся; сохранён переход к конкретному клиенту.

## Ограничения

- Android-устройства нет. Проверка Native Modal `onRequestClose` моделирует Back, не заменяет физическое нажатие Android Back. Настоящий APK, нативная раскладка, увеличенный системный шрифт и экранная клавиатура не проверены на телефоне.
- Браузер использует настоящие RN Web-компоненты и шрифты иконок, но синтетические данные и явно заменённые router/query-cache/storage-связи. Записи меняют только фикстуру; реальная сеть, сервер, БД и очередь телефона здесь не проверяются.
- Сохранённый общий FieldHelp использует символ ⓘ; в текущем Linux Chromium на снимках он отображается прямоугольником. Кнопка, подпись, текст и открытие подсказок проверены в Jest. Общий компонент находится вне области этапа; его исходник сохранён.
- Непрочитанные сообщения, отзывы, обучение и другие отсутствующие нативные сценарии не подменены декоративными блоками. Выборка ближайших работ и вход «Назначить контакт» сохранены; их функциональные отличия из аудита не входят в этот визуальный этап.

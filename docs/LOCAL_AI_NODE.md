# Локальный узел ИИ

Сервер Ведело может первым отправлять текст и аудио на домашний узел с OpenAI-совместимым API. Адреса и ключ задаются в окружении сервера. PWA и Android продолжают обращаться к общим маршрутам Ведело.

| Переменные | Контракт |
| --- | --- |
| `LOCAL_AI_ANALYSIS_URL`, `LOCAL_AI_ANALYSIS_MODEL` | Полный URL чата. Ответ содержит `choices[0].message.content`. |
| `LOCAL_AI_TRANSCRIPTION_URL`, `LOCAL_AI_TRANSCRIPTION_MODEL` | Полный URL распознавания. Принимает multipart `file`, `model`, `language`, `response_format`. JSON-ответ содержит `text`. |
| `LOCAL_AI_API_KEY` | Необязательный токен Bearer для обоих маршрутов. Для сетевого узла используйте приватный канал или HTTPS с авторизацией. |
| `LOCAL_AI_ANALYSIS_TIMEOUT_MS`, `LOCAL_AI_TRANSCRIPTION_TIMEOUT_MS` | По умолчанию 20 и 30 секунд. Допустимые значения от 1 до 120 секунд. Загрузка записи звонка ограничена 15 секундами, облачное распознавание — 45 секундами. |

При сетевой ошибке, тайм-ауте, HTTP-ошибке или пустом ответе запрос переходит к облачному провайдеру, выбранному для организации. Локальный ответ не резервирует облачный баланс. При облачном ответе действует прежняя тарификация. Служебные поля результата указывают фактического провайдера и модель. Фото и импорт с заранее рассчитанной оплатой используют провайдера, выбранного для этой операции.

После трёх неудач подряд сервер пропускает локальный маршрут на семь минут. Предохранитель ведётся отдельно для текста и аудио в каждом процессе. После паузы только один запрос проверяет, восстановился ли узел. Для использования функции нужно настроить узел и проверить доступность его API с сервера Ведело.

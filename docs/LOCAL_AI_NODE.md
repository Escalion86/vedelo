# Локальный узел ИИ

Сервер Ведело может отправлять текст и аудио на домашний узел с OpenAI-совместимым API. Dev-владелец включает локальный ИИ в Web/PWA и выбирает его для анализа, распознавания речи или обоих сценариев. PWA и Android используют общие маршруты Ведело. Переменные окружения задают значения по умолчанию для уже включённого провайдера.

Обратный SSH-туннель выводит сервисы на loopback сервера Ведело. Адреса проверяются при сохранении настроек и перед обращением к сервису. Поддерживаются HTTP и HTTPS на `127.0.0.1` и `[::1]` без учётных данных в URL. Перенаправления отключены.

| Переменные | Контракт |
| --- | --- |
| `LOCAL_AI_ANALYSIS_URL`, `LOCAL_AI_ANALYSIS_MODEL` | Базовый URL чата, например `http://127.0.0.1:18010/v1`. Поддерживается сохранённый ранее полный URL `/chat/completions`. Ответ чата содержит `choices[0].message.content`. |
| `LOCAL_AI_TRANSCRIPTION_URL`, `LOCAL_AI_TRANSCRIPTION_MODEL` | Полный URL распознавания. Принимает multipart `file`, `model`, `language`, `response_format`. JSON-ответ содержит `text`. |
| `LOCAL_AI_API_KEY` | Необязательный токен Bearer. Ключ tenant, заданный через защищённый PATCH настроек ИИ, имеет приоритет. |
| `LOCAL_AI_ANALYSIS_TIMEOUT_MS`, `LOCAL_AI_TRANSCRIPTION_TIMEOUT_MS` | По умолчанию 20 и 30 секунд. Допустимые значения от 1 до 120 секунд. Загрузка записи звонка ограничена 15 секундами, облачное распознавание — 45 секундами. |
| `LOCAL_AI_VOICE_CARD_URL` | Базовый URL экспериментальной голосовой карточки. По умолчанию `http://127.0.0.1:18012`. |

При сетевой ошибке, тайм-ауте, HTTP-ошибке или пустом ответе запрос переходит к облачному провайдеру, выбранному для организации. Локальный ответ не резервирует облачный баланс. При облачном ответе действует прежняя тарификация. Служебные поля результата указывают фактического провайдера и модель. Фото и импорт с заранее рассчитанной оплатой используют провайдера, выбранного для этой операции.

После трёх неудач подряд сервер пропускает локальный маршрут на семь минут. Размыкатель ведётся отдельно для текста и аудио в каждом процессе. После паузы только один запрос проверяет, восстановился ли узел. Кнопка «Проверить подключение» проверяет список моделей чата независимо от состояния размыкателя. Порядок включения и границы проверок описаны в `docs/LOCAL_AI_TEST.md`.

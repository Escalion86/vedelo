# Обратная связь и тикеты поддержки

## Для пользователя

В Web/PWA откройте `Поддержка → Обратная связь`, в Android — `Ещё → Обратная связь`.

1. Нажмите `Новое обращение`.
2. Выберите тип: `Ошибка`, `Идея` или `Вопрос`.
3. Заполните тему и сообщение.
4. При необходимости добавьте до пяти изображений JPEG, PNG или WebP размером до 10 МБ каждое.
5. После ответа разработчика рядом с разделом появится счётчик, а на устройствах с включёнными уведомлениями придёт push.

В списке обращений цвет точки и статусного бейджа обозначает состояние: синий — `Открыт`, янтарный — `В работе`, зелёный — `Решён`. Непросмотренный ответ разработчика дополнительно выделяется акцентной полосой, фоном и меткой `Новый ответ`; после открытия обращения выделение и счётчик исчезают.

Статусы обращения: `Открыт`, `В работе`, `Решён`. Новое сообщение пользователя автоматически переоткрывает решённый тикет. Для отправки тикетов и сообщений в Android требуется интернет; они не попадают в offline-очередь CRM.

## Для разработчика

Роль `dev` видит на той же странице общую очередь всех tenant, автора обращения, переписку и переключатель статуса. Открытие тикета отмечает его прочитанным для стороны, которая его открыла.

## API

Все endpoints принимают web-сессию NextAuth или Android Bearer-токен и возвращают JSON `{ success, data, meta? }`. Пользовательские запросы всегда ограничены текущим `tenantId`; глобальная очередь доступна только роли `dev` вне impersonation-режима.

- `GET /api/support-tickets?status=&category=&cursor=&limit=30` — список тикетов.
- `POST /api/support-tickets` — multipart: `category`, `title`, `message`, `files[]`.
- `GET /api/support-tickets/{id}?cursor=` — тикет и сообщения, по 50 сообщений от новых к более ранним страницам.
- `POST /api/support-tickets/{id}/messages` — multipart: `message`, `files[]`.
- `PATCH /api/support-tickets/{id}` — только `dev`, JSON `{ "status": "open|in_progress|resolved" }`.
- `POST /api/support-tickets/{id}/read` — отметить тикет прочитанным текущей стороной.
- `GET /api/support-tickets/summary` — `{ unreadCount }`, количество тикетов с непрочитанным последним ответом.

Создание ограничено 10 тикетами в час, ответы — 60 сообщениями в час на пользователя/IP. Тема ограничена 160, сообщение — 5000 символами.

## Файлы и push

Сервер проверяет MIME, сигнатуру и размер изображения, затем загружает его в `cloud.escalion.ru` в каталог `artistcrm/{tenantId}/support-tickets/{ticketId}`. Клиент не управляет каталогом, а в БД сохраняются только HTTPS URL Cloud и безопасные метаданные.

Push отправляется после записи сообщения. Ошибка push не откатывает тикет. Payload содержит web-путь в `data.url` и Android-путь в `data.mobileUrl`.

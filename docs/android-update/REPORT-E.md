## Реализация и сквозные контракты

- Просмотр сохранённой работы подключает `EventOnlineSections` → настоящие `EventProposalsSection` и `EventClientReviewSection`. Документы, финансы, контакты, задачи и действия сохранены. Настоящий RN Web измеряет 40×40 во всех light/dark × 360/390/420, без горизонтального overflow и без открытия карточки при нажатии карты. Исходные Stage D browser/gates (включая default native40) побайтово сохранены.

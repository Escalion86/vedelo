# Задачи и события без мероприятия

Проектное решение для согласования. Самостоятельная запись принадлежит сотруднику внутри организации. Она подходит для личных напоминаний, звонков и разовых встреч. Связь с клиентом можно указать по желанию.

## Данные и доступ

Предлагаемая коллекция `PersonalItems` хранит `tenantId`, `ownerUserId`, `kind` (`task` или `event`), заголовок, описание, необязательный `clientId`, `startAt`, `endAt`, `timeZone`, `remindAt`, `status`, `completedAt`, `syncVersion` и временные метки. У задачи дата необязательна. У события есть начало и необязательное окончание. Дата и напоминание хранятся в UTC, часовой пояс IANA сохраняет исходный выбор пользователя при отображении и редактировании. Напоминание можно задать относительно начала или конкретным временем. Без даты доступен только явный выбор времени напоминания.

Запросы фильтруются по организации и владельцу из сессии. В первой версии записи видит только создавший их пользователь. Принадлежность клиента проверяется отдельно. Текущие `additionalEvents[]` и маршруты мероприятий сохраняются. Самостоятельные записи получают отдельные API и тип сущности в Android SQLCipher и outbox. Создание использует `requestId`, обновление — `syncVersion`, удаление — tombstone. Общая лента различает источники парой «тип записи + ID».

## Точки входа и экраны

1. В меню «+» Web и Android — «Задача» и «Личное событие». Форма содержит название, описание, клиента по желанию, дату, время и напоминание. Из карточки мероприятия кнопка «Добавить задачу» по-прежнему создаёт привязанную запись.
2. Во «Важном» самостоятельные дела попадают в общие группы «Просрочено», «Сегодня» и «Завтра». У записи есть подпись «Личная задача» или «Личное событие». Переход открывает саму запись. Завершение и перенос работают по её ID. Незакрытая личная встреча остаётся доступной в списке, но не попадает в финансовое «Закрытие мероприятий».
3. Раздел «Задачи» в меню показывает оба источника с фильтром «Все / Личные / По мероприятиям», сроками и завершёнными. В календарном представлении самостоятельное событие занимает интервал, датированная задача — отметку срока. В списках заявок и заказов самостоятельные записи не влияют на отчёты и суммы.
4. Уведомления получают ключ из типа, ID записи и версии `remindAt`. Перенос аннулирует прежнее время, завершение и удаление снимают отправку. Push-переход проходит обычную проверку входа и доступа. Android показывает офлайн-запись сразу, push доступен после синхронизации.

Перед реализацией нужно согласовать видимость только владельцу и место общего списка в меню. Интеграцию личных событий с внешними календарями можно согласовать отдельно.

## Реализация

Единый нативный FieldHelp/HelpLabel подключён к Field, CompactField, SectionTitle, PageHeader, подписям выбора и автономным переключателям. Зона нажатия 44×44, доступные имя/роль/состояние, заголовок, прокрутка длинного текста, безопасные системные отступы. Закрытие кнопкой, внешним нажатием, повторным нажатием, onRequestClose и событием потери экраном фокуса. При обычном закрытии восстанавливается фокус ввода и фокус доступности; при уходе с экрана возврат на старый экран не выполняется. Действия помощи отделены от действий поля.

В ANDROID-COVERAGE.json представлены все 94 ключа: 67 внедрены в существующие элементы, 20 не имеют соответствующего нативного элемента, 7 относятся к веб-администрированию. Для каждой строки записаны источник, причина, фактические места размещения и состояние существующего веб-перехода. Отсутствие кнопки перехода не выдаётся за выполненную интеграцию. Коммерческие предложения, отсутствующие настройки и новые API не создавались. Генерация DOCX и файловый импорт не объявлены целиком веб-функциями.

Платформенные пояснения перечислены в coverage: текущее Android-устройство для push, отображаемый (не редактируемый) часовой пояс, выбор статуса вместо веб-флажка статистики, ограничения генерации документов, имеющиеся поля webhook/Callback API и переход к Google-импорту. Утверждённые тексты сохранены и сопровождаются пояснениями, а не подменены. Поле «Задаток» с веб-формулой в текущей нативной статистике отсутствует: формулы и остаток к оплате не переименованы.

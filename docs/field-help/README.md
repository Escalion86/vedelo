Требования «точная копия оригинального JSON» и «устойчивые ключи» разделены сознательно: оригинальный массив не содержит ключей, поэтому ключи задаются в отдельном явном реестре, без изменения утверждённых записей. Порядок исходного массива не является идентификатором: генератор ищет пару `source + field`, запрещает пропуск/дублирование и не рассчитывает ключ из индекса.

Выбран вариант генерируемой мобильной копии с тестом равенства, а не чтение внешнего корня через Metro.
